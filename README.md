# Superstore Sales Analysis Dashboard

## Project Overview
This project analyzes Superstore sales data to identify revenue trends, 
top-performing categories, and regional profitability.

## Tools Used
- Microsoft Excel (Pivot Tables, Charts, Dashboard)

## Dataset
- Source: Kaggle - Superstore Dataset
- Records: 9,995 rows

## Key Insights
1. Technology category generates highest revenue (36.4% of total sales)
2. West region is most profitable with 14.9% profit margin
3. Sales grew consistently from 2014 to 2017
4. Central region needs attention - lowest profit margin (7.9%)

## Dashboard Features
- Sales by Category (Bar Chart)
- Monthly Sales Trend (Line Chart)
- Region-wise Sales and Profit (Bar Chart)
